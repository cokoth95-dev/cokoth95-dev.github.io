# Cokoth — Full-Stack Developer Portfolio

A developer portfolio built with **React**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

Designed with a high-end luxury dark aesthetic (matte charcoal with warm amber/orange ambient glow), showcasing real-world production projects, automated M-Pesa sports leagues, cooperative SACCO operations software, Python desktop systems, and an interactive **"Request Access / Demo"** modal for private repositories.

---

## 🚀 Instant Local Preview

To run this site on your local machine:

```bash
cd portfolio
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🌐 100% Free Hosting on GitHub Pages

You can host this site for free on GitHub Pages either as your **primary user site** or a **project site**.

### Option A: As your primary GitHub profile site (Recommended)
1. On GitHub, create a new public repository named:
   ```
   cokoth95-dev.github.io
   ```
2. In your `d:\COKOTH-DEV\portfolio` folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/cokoth95-dev/cokoth95-dev.github.io.git
   git push -u origin main
   ```
3. Go to repository **Settings** → **Pages** → Under **Build and deployment > Source**, select **GitHub Actions**.
4. The included [deploy.yml](.github/workflows/deploy.yml) will build and deploy the site automatically to:
   👉 **`https://cokoth95-dev.github.io`**
